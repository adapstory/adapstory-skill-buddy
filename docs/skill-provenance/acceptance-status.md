Последняя опубликованная ревизия `.codex`: `d11a08b`. Состояние может измениться независимо; перед операцией проверять текущий HEAD и рабочее дерево. SkillBuddy остаётся с незакоммиченными изменениями поверх `8d1013f4fabf80e513a720ee85d0ca3fb73dd539`; среди них есть изменения вне этой задачи. Неотслеживаемые vendor checkout и посторонние изменения `reverse-skill` мешают защищённым операциям приложения, требующим чистого родительского дерева; не удалять их ради обхода этой проверки.

Для негитовых навыков `metadata.skillBuddyProvenance` во frontmatter принимает `{ kind: manual }`, `{ kind: codex }` или `{ kind: archive, url: "https://example.com/file.zip", archiveType: zip }`; прежнее поле верхнего уровня также читается. Вложенная форма совместима с системным валидатором Codex. Это декларация владельца файла, а не проверка авторства. Для собственного навыка Codex сканер отдельно показывает последний локальный Git-коммит его каталога и незакоммиченные изменения; публикация этим не подтверждается. URL с учётными данными, query или fragment не сохраняется; допустимые типы архива: `zip`, `tar`, `tar.gz`, `other`. Подтверждённый Git-манифест и принадлежность плагину имеют приоритет над декларацией.

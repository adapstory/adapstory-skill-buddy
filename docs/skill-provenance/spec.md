# Происхождение навыков: спецификация

## Цель и граница

SkillBuddy учитывает происхождение каждой установки, показывает версии и различия, устанавливает управляемые навыки и обновляет Git-источники с сохранением локальных изменений. В объём входит фактическая миграция обнаруженных глобальных навыков, а также новые установки и полный пользовательский цикл merge. Работа идёт поэтапно: учёт и безопасная миграция, затем установка и обновление в интерфейсе.

## Контракт

1. Сканер учитывает глобальные и проектные установки и навыки плагинов, включая ошибки чтения. Сопоставление по имени не доказывает идентичность. Запись имеет идентичность установки, тип происхождения, известные адрес и путь, свидетельства и неопределённость; секреты не сохраняются. Существующий `SkillOrigin` обозначает категорию расположения и не подменяет происхождение.
2. Происхождение: Git, создан вручную, создан Codex, архив, плагин или «как будто собственный» при недоказанном источнике. Известные URL и типы сохраняются. Для совпадающих происхождений карточка показывает общее значение, для разных — «Разные источники» и значения у каждой установки. Неизвестные данные не выдаются за доказанные.
3. Git-источник представлен приватной копией Adapstory с историей, `origin` и `upstream`, в `~/.codex/vendor/` как подмодуль. Глобальные негитовые навыки принадлежат `.codex`. Проектные навыки остаются в проекте. Навыки плагина продолжают выполняться и обновляться плагином; собственная редакция создаётся явным действием, а дубликат отключается, если платформа позволяет.
4. Управляемая установка использует символическую ссылку при поддержке платформы; иначе копию с отображением потенциального отставания. Нельзя повредить платформенные runtime-проекции, read-only каталоги или сломать обнаружение навыка.
5. Инвентаризация использует lock-файлы, Git, плагины, содержимое и интернет-поиск как свидетельства. Для каждого навыка сохраняются источник доказательства, степень уверенности, план и результат. При доказанном исходном коммите установленное содержимое сохраняется поверх него. При недоказанном коммите версия не выдумывается; при неустановленном источнике используется статус «как будто собственный». Все файлы и ресурсы до и после переноса сравниваются; оригиналы и активные установки не удаляются до проверки и восстановления.
6. Для Git SkillBuddy показывает локальный и доступный upstream-коммиты, diff и состояние локальных изменений. Пользователь запускает merge явно. При конфликте операция остаётся в Git, видны конфликтующие файлы, есть открытие в VS Code и действие завершения после разрешения. Автоматического обновления нет. Для архива фиксируются известные URL и тип; автоматическое обновление архива в объём не входит.
7. Операции SkillBuddy автоматически коммитятся и отправляются с системной авторизацией, без записи секретов. Коммит редактирования включает только файлы операции. При посторонних незакоммиченных изменениях операция останавливается; merge включает весь свой результат. После успешной отправки дочернего репозитория отдельный коммит родителя публикует только указатель и соответствующие метаданные. При ошибке push локальный коммит сохраняется, ошибка видна, принудительный push запрещён, неопубликованный дочерний указатель не отправляется. Внешние правки автоматически не публикуются.

## Критерии приёмки

- Инвентаризация охватывает все доступные сканеру установки; недоступные корни и ошибки учтены отдельно. Для каждой записи есть статус и свидетельства либо явное отсутствие источника.
- Каждая мигрированная установка сохраняет полное содержимое, доступность и действующий статус; сравнение файлов и повторное сканирование подтверждают это. Плагины и проектные файлы не перемещены. Неоднозначные случаи не получают вымышленного upstream или коммита.
- На карточке проверены одинаковое и разное происхождение, плагин, архив и неизвестный источник; копия и ссылка отображаются корректно.
- На реальном Git-репозитории проверены чистый merge, конфликт и восстановление через VS Code, грязное дерево, отклонённый push, сохранение локального коммита и последовательность публикации подмодуля. На реальных адаптерах проверены ссылка, копия и повторное сканирование.
- Прямое редактирование вне приложения не вызывает автоматическую публикацию. Неудача операции не удаляет исходные данные и не маскируется успехом.
- Пройдены профильные проверки SkillBuddy и `make check` родительского workspace. Для недоступного сервиса или неоднозначного источника сохраняются точные ограничения и несданные критерии; завершение не утверждается без фактической миграции.

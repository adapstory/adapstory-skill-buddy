# Происхождение навыков

Контракт и границы: [спецификация](spec.md), [ADR](../adr/0001-skill-provenance.md), [план](plan.md), [термины](../../GLOSSARY.md).

Работа начата, но не завершена. [Состояние критериев](acceptance-status.md) связывает проверки с оставшимися пробелами. Начальный снимок и его ограничения описаны в [инвентаризации](inventory-baseline.md), результаты проверки инструмента — в [tool-assessment](tool-assessment.md). Отчёты `migration-*.md` содержат свидетельства по перенесённым группам. Для `frontend-design` действует [отдельное ограничение](frontend-design-limitation.md). Отчёты не заменяют повторную проверку текущих Git-состояний и установок.

Пользователь разрешил реализацию, перенос, создание и публикацию приватных копий Adapstory и публикацию результатов операций приложения. Работать в основных копиях на `main`, сохранять чужие изменения и перед каждой записью проверять актуальное состояние. Дочерний коммит публикуется раньше родительского указателя. Плагины, проектные навыки и грязный `vendor/gstack` не переносить.

Продолжить с несданных критериев спецификации: проверить оставшиеся глобальные установки и доказательства происхождения, завершить пользовательский цикл установки, проверить конфликт в Electron, затем приложить свидетельства каждого критерия. Не выдавать неизвестный источник или исторический commit за установленный факт. При препятствии сохранить данные и доказательства, продолжить независимые группы и явно указать несданные критерии.

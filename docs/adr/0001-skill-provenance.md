# Происхождение и управляемые копии навыков

Статус: принято пользователем 2026-11-07.

Глобальные навыки из Git поддерживаются в приватных репозиториях Adapstory, подключённых в `~/.codex/vendor/` как подмодули. `origin` указывает на приватную копию, `upstream` — на исходный репозиторий. Это сохраняет историю, локальные доработки и возможность Git merge. Публичный GitHub fork нельзя сделать приватным, поэтому используется отдельная приватная копия истории, а не GitHub fork. Другие глобальные навыки находятся под управлением `.codex`; плагины и проектные навыки остаются под управлением своих владельцев.

Альтернативы: прямые установки из внешнего источника не дают контролируемой общей копии; хранение только lock-файла не обеспечивает историю и merge; перенос навыков плагина в `.codex` без явного действия нарушает владение плагином. Ссылки на управляемую копию предпочтительны копиям, но требуют проверки поддержки платформой. Приватная копия не отображается как GitHub fork. Доступность и лицензия каждого источника проверяются при миграции.
